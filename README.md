# Expense tracker data

Sample trips for [Expense tracker](https://github.com/RSamyak/expense-tracker).  The app is at [rsamyak.github.io/expense-tracker](https://rsamyak.github.io/expense-tracker/).

One folder per trip.  `trip.json` is the settings.  `events/` holds one file per version of an entry.

Make a private repo from this one, then connect it from the app.  The app's readme has the steps.  The sample trip is Asha, Bala, and Chitra, and it is safe to delete.
